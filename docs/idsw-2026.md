# IDSW 2026: schedule overview and a learning plan

Checked 2026-11-21, morning WIB. Source: [idsw.dev](https://idsw.dev), including its schedule section. The site states the schedule is subject to change, so recheck it or the event's social media for late changes.

Provenance: the agenda below is copied from idsw.dev. The "Reading the agenda" and "Suggested learning plan" sections are our own interpretation for a developer who builds personal software with AI assistance; they are not event facts.

## What IDSW is

IDSW (Indonesia Software Developer Conference) is a community-led developer conference run by PERKODI with Indonesian tech communities (Python ID, id-ruby, TEKNUM, JakartaJS, Deeptech.id) - the same crew behind RubyConfID, JSDay, SEA Machine Learning School and PyCon Indonesia. The 2026 edition runs 21-22 November at Usmar Ismail Hall, Jakarta Selatan. Per the site's FAQ, venue tickets are sold out; streaming tickets are sold via TipTip and there is a stream site at [stream.idsw.dev](https://stream.idsw.dev/).

## Reading the agenda (our interpretation)

- **Agentic AI dominates.** Both days open with an agentic-AI keynote, plus talks on agentic coding in a heavily regulated financial company, the first 100 days of AI coding assistants at a large bank, an analytics agent meeting real warehouse data, and a lightning talk on keeping secrets out of LLM agents.
- **LLM systems.** A keynote on inference engineering: the inner workings of fast LLM serving.
- **AI-adjacent craft.** Building a browser engine with AI, design engineering after the "front-end job is dying" claim, human attention, and mentorship for junior engineers.
- **Classic engineering.** Zero-trust networking as a dependency, how voice travels between devices as packets, and one organization-failure talk.

The through-line for a builder of AI-assisted software is "agents meet reality": measured speed claims, production failures, serving costs, secret handling, and verification.

## Suggested learning plan (our suggestion, not event facts)

Written for a developer who builds local-first personal software and LLM tooling, and who publishes research notes while learning.

**Day 1 priorities**

1. Robin's keynote (09:45): agentic workflows on local LLMs. Listen for model sizes, hardware assumptions, and where they still fall back to cloud - the practical boundary for on-device assistants.
2. Thomas's talk (11:10): whether agentic coding actually made a regulated team faster. Listen for how they measured - metrics, review load, incident rates - not just the conclusion.
3. Mustafa's keynote (13:30): inference serving internals. Directly reusable when weighing self-hosted models against APIs: batching, latency, cost per token.
4. Faiq's talk (16:30): what broke when an LLM agent met real BigQuery data. Failure modes of agents on messy production data, useful for anyone wiring agents to personal data stores.

**Day 2 priorities**

1. Mansur's keynote (10:05): from AI prototype to safe, tested, trustworthy production. Compare the verification mindset with how we mark proof boundaries in our own releases (synthetic tests vs device-confirmed behavior).
2. Kresna's talk (13:55): building a browser engine with AI - where AI assistance stops helping on a large, specification-heavy codebase.
3. The lightning block (14:30): especially the SOPS talk on secret handling for LLM agents (relevant to any credential-vault design) and the build-vs-subscribe-vs-on-premise talk.
4. Eko's closing keynote (16:30): topic not yet announced at check time.

**Questions worth carrying** (ours, for Q&A or hallway chats)

- For the local-LLM keynote: what minimum hardware makes an agentic local LLM practical today, and what still forces a cloud fallback?
- For the regulated-industry talk: which agent-written code still needs human sign-off, and how is that enforced in tooling?
- For the analytics-agent talk: what was the first production failure, and how was it detected?
- For the SOPS lightning talk: what is the threat model - an agent reading the repository, or an agent with tool access to a secret store?
