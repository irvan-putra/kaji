# PAN (Webis): a model for sharing research tasks

Checked 2026-11-16. Sources: https://pan.webis.de and https://webis.de/research/tira.html

## What it is

PAN describes itself as "a series of scientific events and shared tasks on digital text forensics and stylometry". Its front page lists tasks per year at CLEF. For 2026: Voight-Kampff Generative AI Authorship Detection, Text Watermarking, Multi-Author Writing Style Analysis, Generative Plagiarism Detection, Reasoning Trajectory Detection. The 2025 list is similar, plus Multilingual Text Detoxification.

## Why it is a useful example

The Webis TIRA page says PAN tasks have been run on TIRA, a platform that hosts shared tasks and takes submitted software instead of only output files. Submitted software is archived so it can be re-run later, including on new datasets. That is the part worth borrowing: a research task shared as a defined problem plus a way to run and compare anyone's attempt, not a loose description.

## Ideas to borrow (our reading, not PAN's claims)

- State each task as a small, named problem with a fixed way to score it.
- Ask for the runnable method, not just the result.
- Keep one page per task, with the round it belongs to.

How much of this fits a small personal project. We have not submitted to a PAN task or used TIRA.
