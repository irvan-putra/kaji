Read sizes correctly

MB and GB below are decimal download units. A download is not RAM or VRAM usage: runtime code, context/KV cache, image encoders and working buffers need extra memory. Different quantizations change file size and output quality. These named artifacts are examples, not universal minimums.

For scale, the optional 218.7 MB SmolLM2 file and the smallest listed 7.76 GB Inkling quant are in very different download classes. Active parameters describe computation, not how many weights must be stored.

6 / 26.4B total parameters, text + image input, text output

Inkling 2 Mini

Named download
7.76 GB to ~20 GB
Unsloth 1-bit: 7.76 GB; 2-bit: 8.49 GB; recommended 4-bit: 17.63 GB. Official mixed NVFP4/MXFP8 checkpoint: about 20 GB. ggml-org 4-bit: 17.6 GB. Vision projectors add separate downloads.
License
Apache 2.0 open weights. Released 20 Nov 2026. Runtime and conversion support still need checking for the exact artifact.
Role and limits
Desktop/local-server class, not a lightweight Daya in-page replacement. Official guidance supports Apple silicon with 32GB+ memory and recommends 32GB+ VRAM on other GPUs. Unsloth gives lower quant-dependent combined-memory estimates, starting around 9GB for 1-bit; these are not conflicting requirements for the same configuration. No phone/browser or current Daya WASM compatibility established.

3.4B active parameters is not a 3.4B-size download. Its looped layers run three passes, giving 5.4B effective active compute per token while storing 26.4B total parameters. Local runtimes need loop-aware support. Coding benchmark claims are not proof of recipe correctness; no Daya reliability evaluation is claimed here.

A model is only one part of the route

A classifier chooses labels; a generator proposes text. Neither replaces validation. Keep description → recipe → validator → deterministic compiler. A schema-valid recipe can still express the wrong intent. Browser-provided AI is a separate runtime/service route, not one fixed downloadable model.

Before choosing an artifact, check its exact license, architecture support, language behavior, memory at the intended context, latency, output correctness and refusal behavior. This catalog publishes no private prompts, personal hardware details or private test results.
