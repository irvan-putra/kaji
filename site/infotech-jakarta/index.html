InfoTech Jakarta: a starting point for tech events

A public Jakarta IT-event resource, with an Instagram feed and a linked calendar. The profile describes IT/technology events, workshops and meetups in Jakarta, mostly free. This is a discovery source, not the organizer or ticketing authority for every event it lists.

What was checked

The signed-out Instagram profile was accessible with the public name Info Event IT Jakarta and the event-focused bio. Its linked calendar, titled Event Tech Jakarta, links back to the same Instagram account. The calendar displayed a 21 November 2026 noon update during this review. A changing event count is deliberately not treated as a permanent fact.

How to use it without a stale plan

  1. Find an event that fits the topic, area and date you want.
  2. Follow the event's organizer or official registration source. Verify the actual venue, date/time, registration deadline, price, eligibility and remaining availability there.
  3. Keep the organizer's confirmation before making travel or attendance plans. A calendar listing, free label or old post does not reserve a place.

The profile's mostly-free description is not a promise that every event is free or still open. Individual events and registration availability were not checked for this resource entry. No posts, attendee lists or private people/contact details are reproduced here.

What this addition does

It adds a public resource link to Kaji. It does not follow the account, send a message, submit an event, connect an Instagram account, subscribe to reminders or start an ongoing event monitor.
