PenGPT in your browser

Type text and a 6M-parameter transformer writes it by hand, or type a phrase and a 54M-parameter one sketches it. Everything runs on your own device: nothing you type leaves this page. Demo code by Sam Greydanus (Apache-2.0), copied unmodified except for an attribution comment. The weights are his, described as open in the repository README with no separate weights license file; this site serves a byte-identical copy (sha256 d678fc79…fd288), also mirrored in the kaji repository's releases. Background and limits: the kaji note and the author's post.

Pick a mode to start the download

Your phone reports a limited or metered connection. The 6 MB mode is friendlier; the 82 MB one is better on Wi-Fi.

Each download happens once per browser and is then cached. Drawing reuses the first part of the file, so if you have already written something it downloads about 76 MB more. The models are small, so generation can still take a few seconds per word or sketch on a phone.

Handwriting: 6M parameters, 1,192 learned hands, picks up an unseen hand from a few real words. Drawing: 54M parameters, blends concepts but does not bind attributes ("facing left" and "facing right" come out the same). More in the note.
